# Research Notes

Durable observations and unresolved design questions live here. A research note
is not an accepted architecture decision. When a design choice is finalized,
record it as an ADR under `docs/decisions/`.

Agent orchestration notes are optional, task-scoped coordination artifacts. Use
one only when a task benefits from parallel agent work, explicit evidence
tracking, handoff continuity, or bounded research review. For small coding,
documentation, testing, or simple research tasks, work directly without adding
orchestration overhead.

Suggested filename:

```text
<topic>-agent-orchestration.md
```
